# Sales Performance Dashboard - Tableau

## Overview
Interactive sales dashboard built in Tableau

## Dataset
- Orders, Sales, Profit, Region, Category data
- 60 orders across 4 regions

## Charts Built
- KPI Cards (Sales, Profit, Quantity, Orders)
- Bar Charts, Line Chart, Scatter Plot
- Pie Chart, Treemap

## Key Insights
- Technology leads in sales
- West region most profitable
- Consumer segment = 46% of sales
